# Smartboard-Spiele · Frau Rie

Klassenspiele für das Smartboard, direkt im Browser – ohne Download, ohne Anmeldung.

**Startseite:** https://fraurie.github.io/spiele/

## Ordner

| Ordner | Inhalt |
|---|---|
| `blitzbild/` | Bild blitzt kurz auf, Wort an die Tafel – nach LE, Alltag, Grammatik, Extra |
| `spiele/` | weitere Klassenspiele (Activity, Wer bin ich?, Zoom-Bild …) |
| `index.html` | Startseite mit allen Spielen |

## Regeln für dieses Repo

- **Öffentlich:** keine Namen, Fotos oder Daten von Schüler:innen.
- Dateinamen ohne Leerzeichen und Sonderzeichen; Niveau als `n1` (●), `n2` (●●), `n3` (●●●).
- Alte Versionen werden nicht aufgehoben – Git speichert jede Änderung automatisch.
